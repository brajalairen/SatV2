Generated by `experiments/adaptation/make_report.py` from the run artifacts. Every number below is read
from a JSON file in this directory; none is typed by hand.

## What was adapted

- **Base model:** `mehmetbayik/Falcon-Single-Instruction-Large` (FalconForConditionalGeneration, 837.4 M params, encoder-decoder with a DaViT vision tower)
- **Method:** LoRA (peft), rank 8, alpha 16, dropout 0.05
- **Adapted modules:** 96 decoder attention projections (self-attention and cross-attention q/k/v/out). **Vision tower frozen.**
- **Trainable parameters:** 1,572,864 (0.188% of the model)
- **Adapter size:** 6.3 MB
- **Adapter SHA-256:** `b7b1388f6c60918877c587e28707c994b64a0798a9ccf9f5c4d9fb0a31336100`

No degradation on the untrained tasks. Binary answers lose their trailing period
(`"yes."` -> `"yes"`), matching the training targets; the app compares answers case- and
punctuation-insensitively, so this changes nothing downstream.

## Limitations, stated plainly

- This adapts to **BigEarthNet Sentinel-2, 120x120 px at 10 m**. It says **nothing** about performance on Cartosat-2S at 0.65 m, and no such claim is made.
- **Binary yes/no rows only.** Bounding-box rows need Falcon's coordinate-token grammar, a separate target that risks regressing the working grounding path.
- **Land-cover class balance is not controlled.** `metadata.parquet` is not available on this machine, so patches were selected from BigEarthNet.txt's own split column and stratified by question category instead.
- Exact-match on short binary answers is a narrow metric. It does not measure caption quality, grounding or change detection, none of which were trained here.
- Confidence values elsewhere in the app remain uncalibrated and are unaffected by this work.
